# ASCOS LegacyRun'a Katkıda Bulunma

Katkılar GNU AGPL v3.0 koşulları altında kabul edilir.

1. Depoyu fork edin ve değişikliğiniz için ayrı bir branch oluşturun.
2. Windows 10/11 uyumluluğunu ve mevcut güvenlik modelini koruyun.
3. Kimlik bilgilerini, parolaları veya kişisel logları commit etmeyin.
4. `build.cmd` ve `build-msi.cmd` ile derlemeyi doğrulayın.
5. Değişikliğin amacı, güvenlik etkisi ve test sonuçlarıyla pull request açın.

Güvenlik açığını herkese açık issue olarak yayımlamadan önce depo sahibine özel
bir GitHub Security Advisory üzerinden bildirin.
